# Common Ground v0.1.0

Common Ground is an open protocol for humans and AI agents editing the same visual workspace. The
agent sends a typed operation; the adapter applies it; the journal checks the capability, records
the ack and inverse, and appends the attempt to a hash-chained audit log. Every accepted turn can
be undone.

This is the first public SDK release.

## Install

```sh
npm install @common-ground/canvas-core zod
npm install @common-ground/canvas-chart zod
npm install @common-ground/canvas-graph zod
npm install @common-ground/canvas-conformance
npm install -g @common-ground/canvas-mcp
```

## What is in the release

- **Protocol v1** — envelopes, acks, turns, capabilities, audit entries, and generated JSON
  Schemas.
- **Chart adapter** — data-space annotations, computed series, snapshot turns, inverses, replay.
- **Graph adapter** — nodes, edges, merge, view state, inverses.
- **Conformance corpus** — six fixtures run against a TypeScript target and the Rust journal.
- **MCP server** — `doc_get`, `op_apply`, `turn_undo`, `state_query` over stdio.
- **Reference app** — Amaterasu, an AI chart analyst that draws through the same op DSL as the
  mouse.

## Limitations

- `0.x`: package APIs may change in minor releases. The protocol version is `1`.
- The MCP server is a thin client over a running journal; it does not store state itself.
- The hosted demo is static and uses sample data; it does not run the agent.
- No CRDT or multi-tenant hosted service yet.

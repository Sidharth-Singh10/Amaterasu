01 / the gap

The agent can see the screen. It cannot touch the document.

Computer use guesses coordinates. MCP standardizes verbs. Neither gives you a stable object, a scoped permission, or a record of what changed.

01

Pixels have no identity

A click at (812, 430) is not a trendline. Layout changes, zoom, a different interval, and the action is gone. Precision domains need coordinates in the data, not the viewport.

02

MCP tools are stateless verbs

draw_line(x1, y1, x2, y2) has no object it created, no inverse, no notion of who authorized it, and no way to undo only that turn.

03

Collaboration assumes humans

Multiplayer infrastructure tracks cursors and human edits. It has no agent actor, no capability scope, no approval gate, and no provenance.

02 / the loop

One write path. Four guarantees.

Every mutation — mouse, agent, or import — becomes the same envelope. The server assigns ids and revisions, the adapter owns projection, and the journal keeps the evidence.

  1. 1

    Typed operation

    Actor, turn, capability, target, idempotency key, and an optional rationale.

  2. 2

    Capability check

    Scoped, expiring grants. Destructive ops can require a one-shot human approval.

  3. 3

    Adapter acknowledgement

    Applied or rejected, with a normalized result, an inverse, or a retry hint.

  4. 4

    Audit and undo

    Hash-chained history. One turn reverts atomically; an undo is a new turn.

07 / questions

Plain answers.

Is this a CRDT?

No. v1 is server-authoritative. The journal assigns revisions and serializes ops. CRDT multiplayer and offline conflict resolution are later work, not claims.

Do I need the Rust service?

No. The SDK is TypeScript. The Rust service is the reference journal, capability issuer, and static host. You can implement the protocol in your own backend; the conformance corpus is how you prove it.

Does it replace MCP?

No. It complements MCP. MCP standardizes how an agent calls a tool; Common Ground standardizes the state that tool mutates, who authorized it, and how it is undone.

What is Amaterasu?

The reference app: an AI chart analyst for Indian markets that draws on the chart through the same op DSL as the mouse. It is the proof that the protocol survives a real, precision-sensitive product.

Can I use it with my canvas?

Yes. Define your object types and ops, implement a store with one write path, compute inverses, and run the six fixtures. The graph adapter is a compact example.
